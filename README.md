# OOP Practical Assignment 5

## Title
Implementation of Class, Objects, This Pointer, Inline Function, Static Member Function and Friend Class in C++.

## Aim
To understand and implement classes, objects, the `this` pointer, inline functions, static member functions, and friend classes in C++.

## Concepts Covered
- **Class and Object:** A class defines data and functions, while an object is an instance of a class.
- **This Pointer:** Refers to the current object and helps distinguish data members from parameters.
- **Inline Function:** A function declared with the `inline` keyword.
- **Static Member Function:** A class function that can access static members of the class.
- **Friend Class:** A class declared as a friend can access the private and protected members of another class.

The program creates Student objects and displays student information. It demonstrates an inline function, a static member function that displays the number of objects created, and a friend class that accesses private student details.
